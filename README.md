# Student Management System

A simple, menu-driven Student Management System developed using Python and MySQL. This project allows users to manage student records through a command-line interface.

## Features
- Add new student records
- View all students
- Search students by ID
- Update student details
- Delete student records
- MySQL database integration
- Exception handling and input validation

## Technologies Used
- Python
- MySQL
- MySQL Connector

## Project Structure
```text
Student-management-system/
├── main.py
├── database.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Installation and Setup

1. Clone this repository.
2. Install the required package:

   `pip install -r requirements.txt`

3. Start your MySQL server.
4. Configure your MySQL credentials in `database.py`.
5. Run the application:

   `python main.py`
